# Initiate Escrow

Creates a new escrow payment session and returns a payment URL. This is used when payment should be held securely until a condition is met.

## Endpoint

```
POST /v1/starpay-api/trdp/escrow/order
```

## Authentication

Include your API secret in the request header.

Header
- `x-api-secret` (string) — Required. Your StarPay API secret key.

Example:

```
x-api-secret: 0nYjAt5ZoTkYQucoywwQnkPUAuQbe2gSkHCGOFZvINBIVIUkqrypzVrxzg4U7Leq
```

---

## Request Body

### orderId

A unique identifier for the order in your system.

Type: `string` — Required

Example:

```
"ESCROW-20260729-001"
```

---

### amount

The amount to be charged to the customer and held in escrow.

Type: `number` — Required

Example:

```
2
```

---

### currency

The currency used for the transaction.

Type: `string` — Required

Example:

```
"ETB"
```

---

### customerName

The full name of the customer making the payment.

Type: `string` — Required

Example:

```
"John Doe"
```

---

### customerPhoneNumber

The customer's phone number.

Type: `string` — Required

Example:

```
"+251912345678"
```

---

### description

A short description of the escrow payment.

Type: `string` — Required

Example:

```
"Escrow payment for marketplace order"
```

---

### callbackURL

A server-to-server notification URL that StarPay will call when the payment status changes.

Type: `string` — Optional

Example:

```
"https://usewebhook.com/e1a0be92923764e90e3608b3b17fe38e"
```

### Successful Callback Example

```json
{
	"orderId": "ESCROW-20260729-001",
	"status": "PAID",
	"timestamp": "2026-09-09T11:05:37.566Z",
	"message": "Payment successful",
	"merchantId": "06783438",
	"customerId": "CUS-1001",
	"amount": 2,
	"payment_type": "USSD_PUSH"
}
```

### Failed Callback Example

```json
{
	"orderId": "ESCROW-20260729-001",
	"status": "FAILED",
	"message": "Payment failed"
}
```


Customer email address.

Type: `string` — Optional

Example:

```
"john.doe@example.com"
```

The date and time when the payment session expires (ISO 8601 format).

Example:

## Next Steps

After initiating an escrow:

1. Redirect the customer to the `paymentUrl`.
2. Wait for a callback notification from StarPay indicating the funds have been secured.
3. Verify the callback signature using your Callback Key.
4. Update the escrow status in your system.
5. When the condition is met, call the Release Escrow endpoint.
